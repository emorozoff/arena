# Оформление

Палитра взята со скриншота сайта шоу, который прислал Егор 7.09.2026: чёрный фон, ярко-оранжевый акцент, белые жирные заголовки капслоком в узком шрифте, тёмные карточки с едва заметной рамкой.

## Цвета (design tokens → `web/src/styles/tokens.css` и Tailwind-конфиг)

| Токен | Значение | Где используется |
|---|---|---|
| `--bg` | `#0A0A0A` | фон всех страниц |
| `--card` | `#111111` | карточки проектов, панели админки |
| `--line` | `#222222` | рамки карточек, разделители |
| `--text` | `#FFFFFF` | основной текст, заголовки |
| `--muted` | `#8A8A8A` | подписи, заглушки закрытых проектов, второстепенное |
| `--accent` | `#FF3B0D` | кнопки, время/метки, акцентные цифры, победитель |
| `--accent-hover` | `#FF5A2E` | кнопка под пальцем |
| `--danger` | `#FF3B0D` | тот же акцент; опасные действия отличаются текстом и подтверждением, не цветом |
| `--ok` | `#3DDC84` | индикатор «связь есть» (единственный не-палитровый цвет, маленький) |

Точные значения оранжевого и серых можно подправить в одном файле, когда будет фирменный гайд.

## Шрифты

- Заголовки, названия проектов, большие цифры: **Oswald** (Google Fonts, есть кириллица), начертание 600–700, капслок, узкий межбуквенный интервал. Ближайший бесплатный аналог шрифта со скриншота.
- Текст, кнопки, подписи: **Inter** (Google Fonts, кириллица), 400–600.
- Цифры денег: табличные (одинаковой ширины), чтобы счётчик на экране не «дёргался» при смене разрядов: `font-variant-numeric: tabular-nums`.
- Запасные шрифты, если Google Fonts недоступен (плохой интернет в зале): системные `Arial Narrow`/`Helvetica Neue Condensed` для заголовков и системный sans-serif для текста. В боевой сборке шрифты кладём внутрь проекта, а не грузим с Google.

## Адаптивность

Страница не определяет устройство, а подстраивается под ширину окна (Tailwind, мобильная вёрстка по умолчанию):
- **до 640 px** — телефон: одна колонка, крупные кнопки;
- **640–1023 px** — планшет: сетки в два столбца там, где есть смысл;
- **от 1024 px** — ноутбук: пульт в две колонки (слева управление, финал и мониторинг; справа проекты), левая колонка «прилипает» при прокрутке.

Названия проектов и спикеров в пульте переносятся по словам, а не обрезаются.

Экран сцены масштабируется от размера окна (`vmin`/`vw`), поэтому одинаково читается на проекторе, ноутбуке и телефоне. Страницы зрителя всегда одна колонка шириной до 448 px по центру.

## Принципы по экранам

- **Телефон зрителя** (`/join`, `/app`): тёмный фон, одна колонка, кнопки не ниже 56 px высотой, свободный остаток крупно наверху оранжевым, свои вложения в карточках белым, заглушки закрытых проектов серым `--muted` без рамки-акцента.
- **Большой экран** (`/screen`, `/screen/results`): фон `--bg`, минимальный размер шрифта 48 px, суммы 160–240 px, полосы в «общем раскладе» оранжевые на тёмном, победитель — оранжевая карточка с белым текстом.
- **Админка** (`/admin`): та же палитра, но плотнее: таблицы, переключатели, опасная зона выделена рамкой `--accent` и подписью.
- Никаких градиентов, теней и стекла: плоско, контрастно, читается с 20 метров.
