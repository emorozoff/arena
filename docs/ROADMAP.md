# План работ

Правило: один этап — одна сессия (или несколько), в конце этапа Егор проверяет руками, только потом идём дальше.
Статус: ⬜ не начат · 🔄 в работе · ✅ принят Егором.

| Этап | Что делаем | Как проверяем | Статус |
|---|---|---|---|
| 0 | **Фундамент.** Документы, правила для Claude Code, git, решение по стеку | Егор прочитал DECISIONS.md и ответил на вопросы | 🔄 |
| 1 | **Каркас + база + админка.** Проект запускается одной командой; таблицы; вход в админку; проекты (добавить/изменить/удалить/порядок/открыть/закрыть); все переключатели шоу; мониторинг | Открыть `/admin`, завести 5 проектов, пощёлкать переключатели, перезапустить сервер — всё на месте | ⬜ |
| 2 | **Вход зрителя.** `/join`, оба режима билетов, cookie, занятый билет, «потерял доступ», закрытие регистрации | Два телефона + ноутбук: войти, повторно открыть, попробовать чужой билет, отвязать в админке | ⬜ |
| 3 | **Голосование.** `/app`, кнопки, серверная проверка, очередь запросов при плохой связи, экран «голосование закрыто» | Спам по кнопкам, две вкладки, выключить Wi-Fi на телефоне посреди нажатий | ⬜ |
| 4 | **Экран.** `/screen`: QR, текущий проект, раскрытие с анимацией, общий расклад; последнее состояние при обрыве | Проектор или телевизор, отойти на 10 метров, выдернуть интернет у ноутбука | ⬜ |
| 5 | **Итоги.** `/screen/results` с пошаговым раскрытием снизу вверх | Прогон финала с клавиатуры | ⬜ |
| 6 | **Нагрузочный тест.** 150 виртуальных зрителей две минуты перекладывают деньги; отчёт: время отклика, ошибки | Ошибок 0, отклик < 1 с, сумма денег сходится | ⬜ |
| 7 | **Деплой + репетиция.** Хостинг, домен, переменные окружения, бэкап базы, чек-лист дня шоу | Полная репетиция «как в бою» с реальными телефонами | ⬜ |

- Экспорт итогов в CSV после шоу.
