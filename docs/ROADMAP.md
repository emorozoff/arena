# План работ

Правило: один этап — одна сессия (или несколько), в конце этапа Егор проверяет руками, только потом идём дальше.
Статус: ⬜ не начат · 🔄 в работе · ✅ принят Егором.

| Этап | Что делаем | Как проверяем | Статус |
|---|---|---|---|
| 0 | **Фундамент.** Документы, правила для Claude Code, git, решение по стеку | Стек принят (D1), команда «начинай» получена 7.09.2026 | ✅ |
| 1 | **Прототип для заказчика.** Весь интерфейс: `/join`, `/app`, `/screen`, `/admin` на React + Tailwind, подключённый к игрушечному серверу в браузере (D16). Сборка в один HTML-файл + ссылка | Егор открывает https://emorozoff.github.io/arena/ на телефоне, переключает роли, двигает деньги, экран «живёт». Отправляет заказчику | 🔄 сделано 7.09.2026, ждёт проверки Егора |
| 2 | **Настоящий сервер + база + админка.** Node + SQLite, таблицы, вход в админку по паролю, проекты (добавить/изменить/удалить/порядок/открыть/закрыть), переключатели шоу, мониторинг, генерация кодов билетов | Открыть `/admin` с Мака, завести 5 проектов, пощёлкать переключатели, перезапустить сервер — всё на месте | ⬜ |
| 3 | **Вход зрителя.** `/join` с настоящим сервером, оба режима билетов, cookie, занятый билет, «потерял доступ», закрытие регистрации | Два телефона + ноутбук в одной Wi-Fi: войти, повторно открыть, попробовать чужой билет, отвязать в админке | ⬜ |
| 4 | **Голосование.** `/app` с настоящим сервером, серверная проверка денег, очередь запросов при плохой связи, «голосование закрыто» | Спам по кнопкам, две вкладки, выключить Wi-Fi на телефоне посреди нажатий | ⬜ |
| 5 | **Экран.** `/screen` с настоящим сервером: QR и общий расклад, SSE, финал с поочерёдным раскрытием из пульта (D21), последнее состояние при обрыве | Телевизор или проектор, отойти на 10 метров, выдернуть интернет у ноутбука, закрыть голосование и посмотреть финал | ⬜ |
| 6 | **Нагрузочный тест.** 150 виртуальных зрителей две минуты перекладывают деньги; отчёт: время отклика, ошибки | Ошибок 0, отклик < 1 с, сумма денег сходится | ⬜ |
| 7 | **Хостинг + репетиция.** Railway, адрес для QR, переменные окружения, бэкап базы, чек-лист дня шоу, формат кодов билетов (D13) | Полная репетиция «как в бою» с реальными телефонами | ⬜ |

Этап 1 — прототип, который можно отправить заказчику файлом. Его интерфейс становится боевым на этапах 2–5: меняется только «сервер за кулисами». Этапы 2–6 — **демо на Маке Егора, бесплатно** (D14): телефоны в той же Wi-Fi. Хостинг подключается только на этапе 7.
